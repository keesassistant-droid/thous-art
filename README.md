# thous-art

Portfolio and commission-request site for painter thous-art. Single-page, client-side routed, no backend (the commission form is simulated).

## Local preview

Open `index.html` directly in a browser, or serve the folder:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy

This repo is set up for GitHub Pages: push to `main`, then enable Pages in the repo settings (Source: Deploy from branch → `main` → `/ (root)`). The site will be live at `https://<username>.github.io/<repo>/`.
